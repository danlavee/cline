# Memory Bank Integrity Checks
As projects progress using cline, the memory bank may drift from its original intention or diverge from the implementation.

This new memory-bank adds an option to perform an integrity check on the memory-bank itself and to compare it with the existing code

* Note that this is an integrity check, not unit testing infrastructure. It is the consistency of objectives and their implementation.

# Example Integrity Check Prompt
 - High level check of API endpoints, entry points and function signatures:  
`Review the integrity check process and perform a high level project integrity check`

- Check core logic only:  
`Review the integrity check process and perform a core project integrity check`

- Full check:  
`Review the integrity check process and perform a full project integrity check`

Based on the project size, not all checks may be suitable.
